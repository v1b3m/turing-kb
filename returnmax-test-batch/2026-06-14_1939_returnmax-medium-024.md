The clean seed is **complete**, so it produces **0 issues**. Live: Check Summary shows **"Looking good! · 0 details for you to review."**
- Check Summary "Continue" (`check-summary/_client.tsx:23-29`) branches on `hasIssues`: **issues → `/issues`**, else **→ `/consent`**. With 0 issues it goes to **consent**. Verified live: landed on `/consent`.
- `/consent` (`_client.tsx:844-916`) renders **both** Step 1 (multi-use) and Step 2 (data sharing) as expandable cards, each "Review and sign" → signature drawer (full name + date + **Agree**). Once **bothDecided**, a single "Continue" → **`router.push("…/max")`** (`_client.tsx:896-906`). So the no-issues path is **consent → max**; it **never visits `/connect-expert`**.
- `/connect-expert`'s **only** inbound link is `issues/_client.tsx:82` (the Chat/Call options live there), reachable **only on the has-issues branch**. So Chat (prompt step 6) is unreachable whenever there are 0 issues.

Only the reachable path (Check Summary → consent → max) is achievable, which omits 3 of the prompt's steps.
