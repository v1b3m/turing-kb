A template belongs to a table. The Table field in the template modal is used to determine which table a template belongs to.

Email templates belong to `Email Log Entry [syslog_email]`
When the dropdown is clicked, it opens a popover with a search input at the top and the list of available tables. I believe when the table is changed, even the available template fields change but for now, let's not worry about this.
