The W-2 Summary page differs from the original TurboTax application in both visual status indicators and available actions.

### **Steps to Reproduce:**

- Navigate to Income.
- Open the W-2 section.
- Reach the W-2 Summary page.

### **Actual Result:**
Each W-2 row displays:

Green checkmark icon
Edit button
Delete icon

### **Expected Result:**
For incomplete or review-required W-2 records, the application should display:

Red circular warning icon with exclamation mark
Review button
Delete icon
