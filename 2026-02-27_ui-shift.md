# Fix Workflow column UI shift on expand/collapse

## Description
When users expand/collapse the workflow stage indicator in the knowledge articles table, the column width changes causing the entire table to reflow — visually jarring.

## Progress
- [x] Add min-w/max-w constraints to lock Workflow column at 280px
- [x] Remove whitespace-nowrap from expanded stage labels so they wrap within fixed width
- [x] Verify build passes

## Decisions
- Used min-w-[280px] + max-w-[280px] to lock column width (min-w alone still allows growth)
- Removed whitespace-nowrap from expanded labels — allows long names like "Scheduled for publish (Skipped)" to wrap within the fixed column

## Outcome
Fixed. Workflow column is now locked at 280px regardless of expand/collapse state. No horizontal shift.
