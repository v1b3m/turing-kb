## What was done
Implemented group-by functionality for the knowledge articles table. When a field is selected from the Group By submenu, rows are grouped by that field value with collapsible group headers showing a play icon, field label, value, and count.

## Commit hash(es)
`c0c338d`

## Files touched
- `src/types/knowledge.ts` (modified) — Added `active` and `articleId` fields
- `src/page-contents/knowledge-articles.json` (modified) — Added `active` and `articleId` data to all 16 rows
- `src/config/knowledge-group-fields.ts` (created) — Mapping from group-by menu labels to KnowledgeArticle fields
- `src/stores/useKnowledgeStore.ts` (modified) — Added `groupByField` and `setGroupBy` state
- `src/components/knowledge/GroupBySubmenu.tsx` (modified) — Wired onClick to set/clear group-by field, highlight active selection
- `src/components/knowledge/KnowledgeArticlesTable.tsx` (modified) — Added GroupPlayIcon, GroupRows components, group computation, expand/collapse state, updated pagination
- `src/components/knowledge/cell-renderers.tsx` (staged) — Pre-existing dependency
- `src/config/knowledge-views.ts` (staged) — Pre-existing dependency

## Decisions made
- **Article ID mapping**: Rows with the same KB number share an articleId (different versions of same article). KB99999999 has empty articleId to match the "(empty)" group in the reference screenshot.
- **Group computation from sorted rows**: Groups are computed after sorting and filtering, so sort order is preserved within groups.
- **Expand/collapse local state**: Used `Set<string>` keyed by group display value. Reset when groupByField changes.
- **Included pre-existing dependencies**: `cell-renderers.tsx` and `knowledge-views.ts` were untracked files from other in-progress tasks that the modified KnowledgeArticlesTable imports. Staged them to keep the commit buildable.

## Known limitations
- "Show just this group" button is rendered but non-functional (no filtering to single group)
- For group-by fields not in `GROUPBY_FIELD_MAP`, all rows group under "(empty)"
- The total count indicator ("16 total Knowledge") shown in the breadcrumb in the screenshots is not implemented
- Selection (checkbox) behavior across groups may need refinement

## How to verify
1. Navigate to `/knowledge`
2. Open hamburger menu → Group By → select "Active"
3. Verify one group: "Active: true (16)" with green play icon
4. Click the group to expand → verify all 16 rows appear with "Show just this group" blue banner
5. Select "-- None --" → verify table returns to normal ungrouped view
6. Select "Article ID" → verify 11 groups with correct counts
7. Click expand/collapse all arrow in the header → verify all groups toggle
