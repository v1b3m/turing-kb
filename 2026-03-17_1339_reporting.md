Here's how to perform each of those reporting actions in ServiceNow:

---

## If you are already on the filtered Case Reports page

If you open:

`sys_report_list.do?sysparm_query=tableSTARTSWITHsn_customerservice_case...`

then you are already looking at saved reports built from the **Case** table.

Use that page like this:

1. Look through the report list first
   - This is the fastest way to see whether a useful case report already exists
   - In ServiceNow, reusing or copying an existing report is usually easier than creating one from scratch
2. Open any report that is close to what you need
   - Examples: cases by state, cases by assigned agent, case volume over time
3. Check the report configuration
   - Confirm the source table is `sn_customerservice_case`
   - Check the filters, grouping, and chart type
4. If the report is close, copy or edit it
   - This is usually the best option for beginners
5. If nothing useful exists, create a new report from the Reports area
   - Good beginner reports are: number of cases by `assigned_to`, number of cases by `state`, number of cases opened over time, number of cases by category

Important:

- Stay on this filtered page for **case-based** reports
- Do **not** use this page for SLA reporting
- SLA reports should use the `task_sla` table instead

## 1. Case Dashboard — Visual dashboard with case metrics and charts

This instance does not expose **Customer Service > Dashboards** in the navigator.

- Navigate to **Self-Service > Dashboards** to open or create dashboards
- You can also use **Platform Analytics > Library > Dashboards** to browse dashboard records
- To build your own: go to **Self-Service > Dashboards**, click **+New**, and add widgets (reports, charts, gauges) by clicking **Add Widget**
- You can pin reports as charts directly to a dashboard by opening any report and clicking **Add to Dashboard**

---

## 2. Agent Performance — Agent-level performance metrics

- Go to **Reports**
- Use the **Case** table: `sn_customerservice_case`
- Open an existing Case report or create a new one. You will not see **assigned_to** on the Reports list page itself
- In the report builder, use **assigned_to** as the field for grouping or filtering
- Start with one simple report such as:
  - **Number of cases per agent**: group by **assigned_to**
  - **Resolved cases per agent**: filter to resolved/closed cases, then group by **assigned_to**
  - **Case volume trend by agent**: trend by **Opened**, then group or filter by **assigned_to**
- If you are new to ServiceNow, think of **assigned_to** as the person currently responsible for the case. That is the main field used for agent performance reporting
- For a more structured view, use **Platform Analytics** content if available in your instance instead of assuming a **Customer Service** report module exists

---

## 3. SLA Compliance Report — SLA achievement and breach statistics

- Go to **Reports**
- Set the **Source table** to `Task SLA` (`task_sla`)
- Filter by `task.sys_class_name = sn_customerservice_case` to scope to cases only
- Group by **SLA** and add a **Has Breached** field to segment compliance vs breach
- Search for **"SLA"** in the Reports list for pre-existing SLA reports, then add the finished report to a dashboard from **Self-Service > Dashboards**
- The `has_breached` (boolean) and `stage` fields on the `task_sla` table are your key fields for this

---

## 4. Case Volume Trends — Case volume over time

- Go to **Reports**
- Set **Source table** to `Case` (`sn_customerservice_case`)
- Choose **Bar** or **Line** chart type
- Set the **Group by** field to **Opened** (date), then choose a **Trend by** interval (daily, weekly, monthly)
- Apply filters as needed (by account, category, state, etc.)
- Save and add to a dashboard for ongoing visibility through **Self-Service > Dashboards**

---

### Pro tip — finding pre-built reports and dashboards fast

- In the filter navigator, search **"Dashboards"** to reach **Self-Service > Dashboards** or **Platform Analytics > Library > Dashboards**
- Under **Reports**, filter the report list by table = `sn_customerservice_case` to see all case reports already in your instance before building from scratch
- Search **"SLA"** in reports when looking for breach/compliance reporting candidates
