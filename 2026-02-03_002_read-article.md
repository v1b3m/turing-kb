### Context

When we click on an open a knowledge article, the default view should be read only.

We need to add a "Checkout" button before the "Retire" button which is supposed to checkout an article for editing. However, this is going to be disabled for now. When clicked, show a "COMING SOON" modal. This modal should be a shared component as all disabled features will show it. So, all inputs should be disabled.

We also need to add an introduction section below the "Short description" which can be scrolled horizontally for lengthy introductions.

The Explantion section then comes after which will contain the full article content. This section should support for rich markdown content. At the moment, we have this section surrounded by a border/outline, we need to get rid of this and render it like another field that renders markdown instead. So "Explanation" should be vertically aligned with all the other fields above i.e "Short description", "Introduction" etc.
