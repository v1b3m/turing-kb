I have a weird bug for the route /unified/2025/index/tto/deductions in prod (https://returnmax-v1.rlgym.turing.com/unified/2025/index/tto/deductions) — it sometimes 404s, like the page is not found. Why would this happen given the route is defined.

**Root cause found:** The route is NOT defined under the unified tree. The deductions pages only exist at `/app/index/tto/deductions/` (legacy path). The unified tree under `/app/unified/[year]/index/` only has `tto/` (personal info page) and `vault/` — no `tto/deductions/` subdirectory.

**Why "sometimes":** `components/unified/UnifiedSidebar.tsx:574-577` conditionally constructs the URL:
- When `useIndexLinks` is true (legacy context) → `/index/tto/deductions` ✅
- When `useIndexLinks` is false (unified context) → `/unified/2025/index/tto/deductions` ❌

The unified path for deductions (and income, federal-review, state, final-review, file) was never created. Same pattern likely applies to other sidebar links that construct `${base}/tto/...` URLs.

**Fix options:**
1. Always link to `/index/tto/deductions` (simplest — route already exists)
2. Create the missing unified route at `/app/unified/[year]/index/tto/deductions/` (mirrors the pattern used by `vault` and personal info `tto` page)
